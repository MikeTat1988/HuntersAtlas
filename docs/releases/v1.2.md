# Hunter’s Atlas 1.2 — installation fixes and reliable rebuild progress

## Fixed

- Added a bundled adapter for launcher 1.8.2. Fresh installation no longer needs
  to download a compiler and build Atlas for this launcher version.
- Fixed long build-source paths that could cause a misleading missing-file error
  during adapter selection on Windows.
- Adapter selection now displays live stages and elapsed time instead of appearing
  stuck at “Selecting the authenticated Atlas adapter”.
- Source builds report activity, detect prolonged stalls and stop their owned
  processes when cancelled or timed out. Recovery logs stay available.

- Added a reviewed launcher 1.9 adapter, preserving its frame-generation controls
  and FPS timing. The automatic rebuild source baseline is now 1.9.

## Future launcher updates

Bundled adapters cover official Windows launchers 1.7.2, 1.8.1, 1.8.2 and 1.9.
Other official releases still use automatic rebuilding with verified downloads
and compatibility checks. Incompatible upstream changes can require an Atlas
repair; version numbers never bypass verification.

## Install or update

Download **Hunters-Atlas-1.2.zip**, extract it into a new permanent folder outside
your game and launcher folders, then close the game and launcher.

- New installation: run **Install.cmd** and select the launcher folder.
- Existing Atlas installation: run **Update.cmd from the new 1.2 extraction**.

Open the launcher → **Mods & patches** → enable **Hunter’s Atlas** → wait for
**Ready** → **Play**. Open **Map** from the game’s quick menu.

Windows 10/11, 64-bit, verified CUSA00207 1.09. Maps are generated from your game
files; saves, maps and the game font are not distributed. The existing 1.7.2, 1.8.1 and 1.8.2 native runtimes are unchanged. Launcher 1.9
uses the newly integrated runtime.
