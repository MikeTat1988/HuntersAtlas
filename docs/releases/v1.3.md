# Hunter’s Atlas 1.3 — independent in-game release

Hunter’s Atlas 1.3 runs with its own tested Windows 1.9 runtime, Python, Tk and required DLLs. Open Bloodborne from the normal desktop shortcut. If the imported preference had Atlas off, enable **Hunter’s Atlas** under **Mods & patches** before choosing **Play**. Then open the native in-game **Map** tile. Use the familiar controller controls and optional lamp travel from inside the game.

## Downloads

- Player package: **Hunters-Atlas-1.3-Windows.zip** — about 177 MB download and 415 MB installed, plus generated caches.
- Source package: **Hunters-Atlas-1.3-Source.zip**.

## Install or update

Extract the complete player package to a permanent folder outside the game and launcher folders, then run **Install.cmd**. Setup imports the selected game, DLC, save location and launcher preferences, and updates the Bloodborne shortcut on the Windows desktop. It may ask for the original launcher folder to locate the existing profile and saves. When migrating from launcher-integrated Atlas 1.2 or earlier, use **Install.cmd** and keep the older folder available for map import; do not uninstall it first because its uninstaller resets maps.

For an update, close Atlas and the game, extract the new package into another folder, and run **Update.cmd from that new extraction**. It preserves the Atlas profile, settings and valid maps; rebuildable caches are recreated as needed. A compatible map pack is reused; when one is unavailable, first Play prepares the maps once from the player’s game files.

Updating a separate ordinary launcher does not replace Atlas or its maps. Atlas runtime updates are delivered through Atlas packages. **Uninstall.cmd** restores the previous desktop shortcut and retains Atlas files, maps and settings. An external legacy hook from an older 1.2 installation is not managed by the 1.3 uninstaller; keep a full copy of the old installation if that integration is needed.

## Verified scope

The stated requirement is Windows 10/11 x64 and Bloodborne CUSA00207 version 1.09. Live gameplay QA was performed on the Windows 11 machine. Automated checks passed: 48 owned-runtime checks (35 installer and 13 contract), 20 legacy bootstrap checks, and 4 asset checks. Eight added installer checks cover Windows Desktop resolution, redirected folders and OneDrive cloud shortcuts. Clean installation included fresh map preparation and a zero-regeneration rerun. Live checks covered the native map tile, pan, zoom, cancel, close/reopen and travel from Cathedral Ward to Hunter’s Dream using copied saves; all 15 live save files kept their original SHA-256 hashes. The owner confirmed the final experience works as expected.

The final geometry screenshot was inspected from the native post-overlay swapchain with fog disabled. The GPU helper was exercised in scaled automatic mode, with the final probe mocked only in that dry run. These results do not claim compatibility with all game builds or GPUs. Game files, generated maps, native font and saves are not distributed.
